# Scientific provenance

This distribution packages the current scientific results from the Yanayacu reviewer edition dated 8 October 2026. The public packaging date is 26 November 2026. Packaging does not create a new biological analysis or change the sample cohort.

Only current results and their required inputs, scripts and execution records are included. Earlier complete deliveries, backup archives, confidential reviewer correspondence and private author working notes are excluded. A required script or source input can predate the present package without representing an alternative analysis version. Source manifests retain those relationships and file hashes.

There are nine analytical soil units, A1–A3, B1–B3 and M1–M3. Both 16S and ITS measurements belong to these same units. J denotes Jaén and SI denotes San Ignacio. The original fertile-soil unit P1 is retained in original sequence deposition records but is excluded from the comparative analyses.

The released analytical values and the original recorded soil measurements are distinguished explicitly. In particular, particle-size preparation is retained as a documented data transformation; it is not a corrected laboratory measurement. Units and laboratory methods that have not been verified from primary documentation are not invented.

Computational scripting, numerical checking, data-derived figure preparation and documentation received assistance from OpenAI ChatGPT and Codex. Execution is performed by the scientific software specified in the accompanying scripts and environment records. Responsibility for scientific interpretation and publication remains with the study authors.

Reproduction receipts state exactly what was executed. Successful byte checks or numerical replay do not establish independent biological replication, resolve missing laboratory records, or constitute a complete new execution from raw FASTQ files.
